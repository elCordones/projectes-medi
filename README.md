* **🌍 Web en línia (GitHub Pages):** [https://elcordones.github.io/projectes-medi/](https://elcordones.github.io/projectes-medi/)
* **Obrir en local (servidor de desenvolupament):**
  ```powershell
  npm run docs:dev
  ```
* **Compilar web estàtica de producció (`.vitepress/dist`):**
  ```powershell
  npm run docs:build
  npm run docs:preview
  ```
* **Desplegar a GitHub Pages amb un sol clic:**
  ```powershell

  ```

## 📘 Estàndard Oficial de Programació SdA
Tots els projectes segueixen el protocol del skill global [`disseny-sda`](file:///C:/Users/dcordone/.gemini/config/skills/disseny-sda/SKILL.md) i la normativa del Decret 175/2022 i Decret 480/2024 de Catalunya:
- **Estructura en 12 Seccions Oficials** del Departament d'Educació.
- **Formulació Rigorosa:** Objectius d'aprenentatge (`Capacitat + Saber + Finalitat`) i Criteris (`Acció + Saber + Context`).
- **Seqüència en 8 Sessions (Model 5E)** amb activitats Inicials, Desenvolupament, Síntesi/Estructuració i Aplicació/Transferència.
- **Avaluació Triangular 360° (CoRubrics):** 50% docent, 20% coavaluació entre iguals d'exposició, 15% coavaluació interna d'equip i 15% autoavaluació + Kahoot col·laboratiu.
- **Sortida Dual Garantida:** Generació sincronitzada del document en Markdown (`SdA_Projecte_[Tema].md`) i en Microsoft Word (`.docx`) maquetat amb estils institucionals i taules ombrejades.
